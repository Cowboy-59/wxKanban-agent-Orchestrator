# Reports

Reports gives you analytics on time, projects, and team performance — the numbers behind the work. Use it to see where hours are going, how projects are progressing, and how the team is performing over a period you choose.

> **Plan note:** Reports is a **Consultant plan** feature; on Small Business the sidebar link shows a padlock. See [Help](help.md) to compare plans.

## What you're looking at

Two report-type tabs — **Time Reports** and **Project Reports** — switch what's analyzed. A **Date Range** with **Start Date** and **End Date** pickers scopes the data, and **Export CSV** downloads the current report for use in a spreadsheet. The panel below (for example, **Time by Team Member**) shows the results once you pick a range — until then it prompts "Select a date range to view time reports."

## Running a report

1. Choose **Time Reports** or **Project Reports**.
2. Set the **Start Date** and **End Date**.
3. Read the resulting breakdown (for time reports, hours logged per team member).
4. Optionally click **Export CSV** to download it.

## Common tasks

1. **See hours by person:** open **Time Reports**, set a date range, read **Time by Team Member**.
2. **Review project progress:** switch to **Project Reports**.
3. **Get the data into a spreadsheet:** click **Export CSV**.

## Fields and what they show

- **Time Reports / Project Reports** — which dimension is analyzed (hours vs. project progress).
- **Date Range (Start / End)** — the window the report covers.
- **Time by Team Member** — hours logged by each person in the selected range.
- **Export CSV** — downloads the current report as a CSV file.
