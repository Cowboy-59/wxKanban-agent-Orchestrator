# Projects

The Projects screen is the full, searchable list of every project in your company. Come here to find a specific project, filter projects by lifecycle phase, or create a new one. It's the list-view counterpart to the card grid on the [Dashboard](dashboard.md).

## What you're looking at

The header shows the project count (e.g. "15 projects") and a **+ New Project** button at the top right. Below it is a row of **phase-filter tabs**, then a search box and sort controls, then the list itself.

## Filter by phase

The tabs — **All · Design · Implementation · QA Testing · Human Testing · Beta Release · Release** — narrow the list to projects currently in that lifecycle phase. **All** (the default) shows everything. Use these to answer questions like "which projects are ready for QA?"

## Search and sort

- **Search projects…** filters the list as you type, matching on project name.
- **Sort** offers **Updated** (most recently changed first — the default), **Created** (newest first), and **Name** (alphabetical).

## The project list

Each row shows the project **name**, a **phase badge** (e.g. *Design*), and a **scope summary** — how many scopes it has and their states, such as "73 scopes · 67 planned · 6 draft" or "54 scopes · 1 implemented · 2 implementing · 7 tasks ready · 24 planned · 1 in review · 6 draft". A small **AS**-style avatar on the right of some rows indicates an assigned owner or consultant. Click any row to open it — see [Inside a project](project-detail.md). Click **+ New Project** to create one (same result as **New** on the Dashboard).

## Common tasks

1. **Find a project:** type part of its name in **Search projects…**.
2. **See projects in a given phase:** click that phase tab (e.g. **Implementation**).
3. **Open a project:** click its row.
4. **Create a project:** click **+ New Project**, enter name and description, save.
5. **Sort by most recent activity:** leave sort on **Updated** (the default).

## Fields and what they show

- **Project count** — total projects matching the current filter.
- **Phase badge** — the project's current lifecycle phase.
- **Scope summary** — the number of scopes and a breakdown by state (draft, planned, implementing, implemented, in review, tasks ready). "Overview doc" appears when the project has a generated overview.
- **Owner/consultant avatar** — the initials of the person or firm associated with the project.
- **Search** — filters by project name.
- **Sort (Updated / Created / Name)** — controls list order.
