# Work Hub

The Work Hub is a consultant-focused command center: one unified queue of assigned work across all projects, with at-a-glance health tiles and a preview of what's ready to bill. Use it when you're doing the work (rather than administering the company) and want a single prioritized list plus one-click time tracking.

## What you're looking at

The header carries the title, a **project filter** (the funnel icon and the **All Projects** dropdown) to scope everything on the page to one project, and four **status tiles**:

- **Total Tasks** — all tasks in your queue.
- **Past Due** — tasks whose due date has passed (highlighted amber).
- **30+ Day Aging** — tasks sitting untouched for over a month (highlighted red).
- **Compliance** — tasks flagged by a compliance audit that need attention.

## Assigned Work Queue

Below the tiles is your **Assigned Work Queue** — the tasks assigned to you, drawn across every project (or the one you filtered to). Each entry supports one-click time tracking so you can start logging against a task without leaving the page. When nothing matches, it reads **"No assigned tasks found for this filter."**

## Invoice-Ready Billable Preview

The **Invoice-Ready Billable Preview** shows billable time in a date range you set with the two date pickers — a preview of what could become an invoice. Alongside it, the **Compliance Review Panel** lists any tasks a compliance framework has flagged, with a running "Compliance flagged tasks" count, so nothing non-compliant slips into a bill.

> Note: turning billable time into an actual invoice happens on the [Invoices](invoices.md) screen, which requires the Consultant plan. The Work Hub *preview* is available here regardless.

## Common tasks

1. **Focus the hub on one project:** pick it in the **All Projects** dropdown.
2. **See what's slipping:** read the **Past Due** and **30+ Day Aging** tiles.
3. **Preview what you can bill:** set the start and end dates under **Invoice-Ready Billable Preview**.
4. **Check for compliance flags before billing:** read the **Compliance Review Panel**.

## Fields and what they show

- **Total Tasks** — count of all tasks in your assigned queue.
- **Past Due** — tasks past their due date.
- **30+ Day Aging** — tasks with no progress for 30+ days.
- **Compliance** — count of compliance-flagged tasks.
- **Assigned Work Queue** — your tasks across projects, with inline time tracking.
- **Invoice-Ready Billable Preview (date range)** — billable hours in the selected window.
- **Compliance flagged tasks** — how many queued tasks a framework flagged.
