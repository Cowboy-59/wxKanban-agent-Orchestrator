Getting Started with wxKanban

From a brand-new computer to a working setup inside VS Code — even if you've never installed a developer tool before. Follow it top to bottom.

⏱ ~30–45 min the first time No programming experience required Windows & Mac
1

What is wxKanban — and why these tools?

wxKanban is not a "click a button and get an app" generator. It's an orchestration kit that walks your project through a disciplined 6-phase lifecycle — Design → Implementation → QA → Human Testing → Beta → Release — and only lets you take the right action at the right time. Specs get followed. Tests don't get skipped. Releases don't happen without QA.

The goal isn't to hand you code. It's to build your judgment — so you learn how to ship tested, audited software on a repeatable process. To do that, four tools work together:

Your workshop

VS Code

The editor where all your work happens.

Your AI dev agent

Claude Code

Claude Code — or your preferred AI development agent — inside VS Code.

Your dashboard

wxKanban Dev Cockpit

A sidebar showing what's built and what's next.

Your project's memory

wxKanban service

The brain that enforces the lifecycle and stores your project.

Install the prerequisites

Install these three first. On Windows, do each install, then close and reopen VS Code / your terminal afterward so it picks up the changes.

Node.js 20 LTS

wxKanban runs on Node.js. Get the LTS version (20 or newer) from nodejs.org — click the LTS button and accept all defaults. Then verify:

node --version

You should see something like v20.x.x.

Git

Windows: install from git-scm.com, accept defaults. Mac: run git --version; if it's missing, macOS offers to install it.

Why it matters on Windows: without Git, Claude Code falls back to PowerShell and some scripts behave differently.

Visual Studio Code

This is the editor everything runs inside. Download from code.visualstudio.com. On the Windows installer, tick "Add to PATH" and "Open with Code" if offered.

Opening a terminal inside VS Code: press Ctrl+` (the backtick key, top-left) — Mac: Cmd+`. On Windows this is a PowerShell terminal by default. You'll type commands here.

Install Claude Code — if you use (or want to use) it

This is the piece to get right — Claude Code is how you'll actually do the work.

Install the VS Code extension

  1. Open the Extensions panel: Ctrl+Shift+X (Mac: Cmd+Shift+X).
  2. Search for Claude Code.
  3. Install the one published by Anthropic — id anthropic.claude-code.
  4. Restart VS Code if it asks.

Install the command-line tool

The chat panel works on its own, but the wxKanban kit also needs the claude command available in the terminal.

Windows (PowerShell):

irm https://claude.ai/install.ps1 | iex

Mac / Linux:

curl -fsSL https://claude.ai/install.sh | bash

Then close and reopen the terminal and verify:

claude --version

Sign in

Run claude in the terminal (or click the Claude icon in the top-right of VS Code) and choose one:

  • Claude Pro or Max subscription — easiest for individuals. A browser opens; sign in with your Claude.ai account.
  • Anthropic API key — for teams / billing control. Create one at console.anthropic.com and paste it when prompted.

Your login is saved securely; you only do this once.

Get your wxKanban project

  1. Sign in to the wxKanban web app (your account URL, e.g. wxkanban.com).
  2. Create a project (or open the one created for you). This registers it in the hosted service and gives it a unique Project ID.
  3. Click the KIT link on the project you just created (in project edit mode) and generate a kit for that project. It gives you a zip file to download. Create the directory you're going to do your development in and unzip the contents into that directory — you'll get .wxkanban-project.json (your Project ID + kit version), the wxkanban-agent/ kit, and the vscode-extension/ Cockpit installer.
  4. In VS Code: File → Open Folder… and open that project folder.
The kit is generated per project — it carries that project's ID, so a kit downloaded for one project will not work for another. If you create a second project later, generate a fresh kit for it rather than copying this folder.

Wire wxKanban into your project

Do these inside VS Code, in the integrated terminal (Ctrl+`), from your project folder.

A fresh kit is mandatory for every project you create. Each new project gets its own kit — don't reuse a kit from another project.

Install dependencies step 1

The kit setup normally installs these for you. If it didn't, run:

npm install

Install the Dev Cockpit extension step 2

The Dev Cockpit is installed from the extensions automatically. If the wxKanban icon doesn't appear in the left activity bar, install it manually:

  1. Open Extensions, search for wxKanban, and follow the instructions.

A wxKanban icon appears in the left activity bar — that's your Dev Cockpit.

Allow the automatic tasks step 3

When the folder opens, VS Code may ask "This workspace has tasks configured to run on folder open. Allow?" — click Allow (or Allow and Remember). These keep your kit up to date and start the orchestrator.

At the top of the Cockpit there will be a status for the Orchestrator and MCP — both should show OK.

You're set up. 🎉

7

Your first workflow

You describe what you want in plain language in Claude Code, and the kit handles the specs, code fencing, tasks, and audit trail.

  1. See where you are — open the Dev Cockpit sidebar (the wxKanban icon). It shows remaining work per scope, active scope pinned, updating live as work is built.
  2. Design first (mandatory). Before any code, define scope. In Claude Code run /buildscope — it interviews you section by section (you approve each step) to produce a Scope-of-Project document.
  3. Turn scope into specs & tasks: run /createSpecs for the specification, plan, and task breakdown.
  4. Build it: run /implement. The orchestrator implements tasks one at a time, fencing each and keeping the audit trail intact.
  5. Advance through the phases — QA, Human Testing, Beta, Release — each with its own gated commands. The Cockpit and /help always show what's available right now.
Golden rule: If it's not in the spec, stop and add it to the spec first. This one habit prevents most of the surprises that derail projects.

Type /help in Claude Code anytime to see every command available at your current phase.

Troubleshooting

claude command not found

Close and reopen the terminal after installing. On Windows, make sure you ran the PowerShell install (irm … | iex), not the Mac one.

Claude Code icon / panel not showing

Open a file (not just the folder). Update VS Code to the latest version. Or use Command Palette → Claude Code: Open.

MCP won't connect after restart

Re-register and re-approve:

node scripts/init.mjs

Then restart VS Code and run /mcp again to approve wxkanban.

Cockpit sidebar is empty

Make sure .wxkanban-project.json exists in the folder you opened, and that npm run kit:health reports healthy. Then Command Palette → wxKanban: Refresh Cockpit.

Kit tasks not running on folder open

Command Palette → Tasks: Manage Automatic Tasks in Folder → Allow Automatic Tasks in Folder.

PowerShell vs CMD confusion (Windows)

A prompt starting PS C:\> is PowerShell — use the irm install commands. Don't mix PowerShell and CMD syntax in one command.

Where to get help

  • In VS Code: run /help in Claude Code for the full command list at your current phase.
  • Report a bug / suggest a feature: Command Palette → wxKanban: Report a Bug / Suggest a Feature — routes straight into the team's queue.
  • Claude Code docs: code.claude.com/docs
