# wxKanban Beta — Application Form

**Purpose:** select 5 beta testers for a hands-on, done-with-you conversion of their own
WINDEV application. This form qualifies applicants — friction is intentional. A serious
developer fills it in ~5 minutes; a tire-kicker bails (which is the point).

**Recommended tool:** Tally or Google Forms, emailing each submission to andy@wxperts.com.
Don't build a custom form into the app for 5 people. (KISS.)

**Header shown above the form:**

> **Apply to convert your WINDEV app with me — 5 spots only.**
> wxKanban releases at the end of June. I'm taking just 5 beta testers and working
> hands-on with each of you to convert your own WINDEV application to AI-built,
> full-stack software you own. I read every application personally.

9. **Which database does it use?**

   - Other (please specify)
10. **Is it live in production today?**
    - Yes — real users
    - Internal only
    - Prototype / not yet live
11. **Do you have full access to the source code *and* the data?**
    - Yes, both

    - No
