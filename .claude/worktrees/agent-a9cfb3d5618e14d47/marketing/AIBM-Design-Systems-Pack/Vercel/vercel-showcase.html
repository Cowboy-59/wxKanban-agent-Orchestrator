Design System
Analysis of Vercel

A near-black, almost monochrome system carried by a single near-white ink, structured with 1px hairlines instead of shadows, and accented by one electric blue — set in Vercel's own Geist typeface with Geist Mono for technical eyebrows.

02 — Foundations

Typography

Set in Geist — Vercel's own open-source grotesque — with Geist Mono for eyebrows and labels. Hierarchy is built through size and tight negative tracking far more than weight; the display tiers run a punishing −0.06em.

04 — Components

Cards & Surfaces

Cards rarely take a fill — they sit on the canvas and are drawn by a single 1px ring, lifting to a brighter white-alpha ring only on hover.

06 — Foundations

Spacing Scale

Built on a 4px base unit (--geist-space); 24px is the default column and section gutter.

07 — Foundations

Border Radius

A small, tight radius family — 6px is the workhorse default; the full pill handles CTAs, tags, and avatars.

08 — Foundations

Elevation & Depth

Level 0 — 1px hairline only. The resting state of every card and button (ring at #2e2e2e).
Level 1 — a brightened white-alpha ring on hover, plus a faint drop shadow.
Level 2 — true float: menus, popovers, and modals (--ds-shadow-medium).
09 — Responsive

Responsive Behavior

NameWidthKey changes
Mobile< 768pxSingle column; fluid clamp() type scales the 64px display down; CTAs go full-width.
Tablet768–1023pxTwo-column grids; primary nav condenses to a menu.
Laptop1024–1279pxThree- and four-column grids; content held within the 1400px max width.
Desktop≥ 1280pxFull 1400px canvas with 24px margins; hero gives one object the centre.

Token-first responsiveness. Type and spacing interpolate continuously via clamp()-based --text-fluid-* and --spacing-fluid-* variables, so sizes glide between breakpoints rather than snapping — there are very few hard layout jumps.
