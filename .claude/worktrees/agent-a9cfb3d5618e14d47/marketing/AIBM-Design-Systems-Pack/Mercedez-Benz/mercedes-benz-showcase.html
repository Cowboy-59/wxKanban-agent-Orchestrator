Design System
Analysis of Mercedes-Benz

A disciplined monochrome system — white, black and a cool grey ramp — where colour comes only from photography and the brand voice lives in the proprietary MBCorpo typefaces and a single white pill CTA.

04 — Components

Cards & Surfaces

Cards are sharp-cornered and flat — a full-bleed image with the caption set beneath it. Depth is reserved; a subtle shadow appears only on hover.

06 — Foundations

Spacing Scale

A roughly 8 px base unit drives a generous vertical rhythm that lets full-bleed photography breathe.

07 — Foundations

Border Radius

Almost everything is sharp (0 px). The one expressive move is the 16 px pill button; circular controls go fully round.

08 — Foundations

Elevation & Depth

Level 0 — 1px hairline only. The default: the interface is overwhelmingly flat, with no resting card shadow.
Level 1 — a soft lift for hovered cards and dialogs (normalized for the showcase).
Level 2 — deeper shadow for overlays and menus. On the live site, the only real shadow is a heavy 0 3px 7px rgba(0,0,0,.8) used to lift white text off photography.
09 — Responsive

Responsive Behavior

NameWidthKey changes
Mobile< 768pxTeaser tiles stack to one column; headline scale drops to the 48px tier; nav collapses behind a menu trigger.
Tablet768–1023pxTwo-column teaser grid; hero stage keeps full-bleed image with the pill CTA pinned bottom-left.
Laptop1024–1279pxFull multi-column teaser tiles return; editorial bands run edge to edge.
Desktop≥ 1280pxDisplay headlines reach 64–72px; content centres within a ~1200px reading measure.

The page is a stack of full-width editorial and teaser bands rather than a boxed grid, so it reads like a magazine. The translucent header scrim and the white pill CTA persist unchanged across every breakpoint.
