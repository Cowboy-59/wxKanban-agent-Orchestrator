Design System
Analysis of Headspace

A warm, calming system built on a sand-toned canvas and soft charcoal ink, where a single confident cobalt blue carries every action and a sunny marigold yellow plays the brand's friendly accent.

06 — Foundations

Spacing Scale

Built on an 8px base unit (with a 4px sub-step), scaling to a generous 64px rhythm between major sections.

07 — Foundations

Border Radius

Roundness is the signature — from a 2px hairline detail up to fully-rounded pills on the largest hero CTAs.

08 — Foundations

Elevation & Depth

Level 0 — 1px hairline only. The resting state for most cards; depth is implied by the warm border, not a shadow.
Level 1 — soft low shadow (0 1px 8px) used on card hover to gently lift content off the page.
Level 2 — a diffuse glow (0 0 18px) reserved for floating menus and modal surfaces.
09 — Responsive

Responsive Behavior

NameWidthKey changes
Mobile< 768pxGrids collapse to one column; display headlines drop to ~36–40px; side margins tighten to ~22px.
Tablet768–1023pxCard grids go two-up; hero display steps down to ~48px; CTAs stack.
Laptop1024–1279pxFull multi-column grids return; centered column with wide calm margins.
Desktop≥ 1280pxMax content width ~1200px; generous 64px+ vertical rhythm between bands.

Layout note: A centered column with airy margins, alternating sand and white (or colored) full-width bands to segment the long marketing page.
