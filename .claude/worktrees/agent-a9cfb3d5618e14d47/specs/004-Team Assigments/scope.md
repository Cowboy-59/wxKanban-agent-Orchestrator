# team assignment duties #

  Each team member of the project should have duties to perform such as 
    Developer
    Design Coordinator
    System review
    TeamManager
    Q/A
    Final Acceptance Review
    Publisher
    Security TeamManager 
    ALL

    All this is based on the Project Security being set to either HiTrust or SOC 2. 
   
   Admin can add or remove duty types for their subscription as needed so these are defaults that will be created at time of subscription start.

   as a task is completed, the system should attempt to assign to the next Duty, or ask user which to assign to from list available.

   if ALL is the only choice , then no questions are asked and all are assigned to the user as this is a single source project.

   the Team Manager can assign more than one duty to a team member as long as it conforms to both SOC 2 and HiTrust rules, if one of the rules is being broken, a Warning is shown and the Team Manager can still assign if reason for assignment is added
