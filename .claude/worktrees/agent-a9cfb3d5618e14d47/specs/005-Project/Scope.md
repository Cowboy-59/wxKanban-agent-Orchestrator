# Project defintions/scope #

## Project Overview ##

   Project file definition  is based on one of 2 , internal or not internal 
   all projects default to true on INTERNAL 
   if internal is true company information is automatically displayed on page 
      Fields not Used:
        BaseRate is not used , disable
   if internal is false user can add in company info for project

   add the lifecycle sections to each project 
    LifeCycle Phase 1 -- design and create all tasks
    LifeCycle Phase 2 -- Coding and functionality / implemtation
    LifeCycle Phase 3 -- Q/A testing 
    LifeCycle Phase 4 -- Human testing with feedback
    LifeCycle Phase 5 -- Beta Release with feedback
    LifeCycle Phase 6 -- Release

   ### Project Tasks ### 

   for each project there is the lifecycle setup each phase automatically set for each Spec functionality.

   example: Administration, accounting, one for each spec created in the specs folder.

   tasks created under each spec folder will associate with the Folder name as section.
   Documentation for each will also be a default task that will be managed.
