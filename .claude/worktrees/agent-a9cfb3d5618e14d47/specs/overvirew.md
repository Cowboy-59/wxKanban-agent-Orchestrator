    Lifecycle Phase 2 -- Coding and functionality / implementation
    Lifecycle Phase 3 -- Q/A testing (including possible SOC 2, or HITRUST documentation) (automated)
    Lifecycle Phase 4 -- user testing with feedback
    Lifecycle Phase 5 -- Beta Release with feedback
    Lifecycle Phase 6 -- Release
