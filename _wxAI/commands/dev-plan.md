# dev-plan — Development Plan (Build Roadmap)

Produces the artifact you read *first* when returning to a project: one page answering
**"where am I, what's built, what do I build next, and what's in the way."** It groups the
project's specs into foundation-up phases, draws the dependency graph as a color-coded Mermaid
diagram, and renders the whole thing to a print-ready PDF.

This command runs the **`dev-plan` skill**. Invoke the skill, then follow its workflow:

1. Gather build state per spec (read `specs/###-*/spec.md` + `tasks.md`; consult the dashboard/memory).
2. Derive the dependency graph and foundation-up phases.
3. Write `specs/DEVELOPMENT-PLAN.md` (START HERE block, status table, Mermaid map, phased build order with exit gates).
4. Render the PDF: `node .claude/skills/dev-plan/scripts/build-devplan-pdf.mjs` → `specs/DEVELOPMENT-PLAN.pdf`.

## Where it shows up

- **Dev Cockpit** — a read-only **"Development Plan"** panel renders the deterministic checklist
  (✓ done · ◐ in progress · ○ not started per scope), sourced from `cockpit_summary`.
- **Web app** — the Admin Dashboard per-project **"Development Plan"** link opens the PDF (review + print).
- **Auto-refresh** — the deterministic `devplan` doctype is regenerated by the MCP server on every
  `create_specs` / `implement` (no LLM); this command adds the judgment narrative + PDF on demand.
